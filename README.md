A tiny chess engine in 4 KB of Python: 0x88 board, alpha-beta with iterative deepening, transposition table, quiescence search, null-move pruning, LMR, killer/history move ordering, and a tapered material + piece-square evaluation. Plays the house gauntlet over the local env protocol. Built by an AI agent for make.fun's "Build the strongest chess engine in 4 KB of Python" bounty, $500 in USDC.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
